2. Chi tiết 5 Trụ Cột Giám Sát Sức Khỏe (Monitoring)

A. Giám sát Ứng dụng & Serverless (Vercel)

  • Vercel Runtime Logs: Theo dõi real-time các request. Lọc status 500 hoặc 504 Gateway Timeout.
  • Speed Insights: Giám sát Core Web Vitals của 78 trang lá bài (LCP < 2.5s, CLS < 0.1, INP < 200ms).
  • Cron Jobs: Kiểm tra trạng thái chạy thành công của 2 job dọn dẹp (expire-orders & rate-limits).

B. Giám sát Database & Phân quyền Bảo mật (Supabase)

  • Tài nguyên máy chủ: CPU usage duy trì < 30%, RAM ổn định, Disk IOPS không bị nghẽn.
  • Auth Logs: Theo dõi tỷ lệ đăng nhập thành công qua Google OAuth và Email OTP.
  • Sao lưu dữ liệu: Kiểm tra Daily Backups được lưu trữ an toàn trên Supabase.

3. Đối Soát Dòng Tiền & Chống Gian Lận Credits (Ledger Audit)

Nguyên tắc Sổ cái kép: Số dư tại profiles.credits bắt buộc phải bằng tổng tất cả giao dịch nạp/trừ trong bảng ledger. Không có bất kỳ API nào được phép update trực tiếp cột credits.

Câu lệnh SQL đối soát tự động trên Supabase SQL Editor:

-- Kiểm tra phát hiện tài khoản bị lệch credits:
SELECT 
  p.id, p.email, 
  p.credits AS current_credits,
  COALESCE(SUM(l.amount), 0) AS calculated_credits,
  (p.credits - COALESCE(SUM(l.amount), 0)) AS diff
FROM profiles p
LEFT JOIN ledger l ON p.id = l.user_id
GROUP BY p.id, p.email, p.credits
HAVING (p.credits - COALESCE(SUM(l.amount), 0)) != 0;
💡 Đánh giá kết quả: Nếu query trả về 0 rows, toàn bộ tài khoản và dòng tiền trên hệ thống hoàn toàn cân bằng và chính xác 100%.

4. Kiểm Soát Chi Phí & Hạn Mức API AI

Hạng mục Cơ chế kiểm soát Mục tiêu an toàn

6. Sổ Tay Ứng Cứu Khẩn Cấp (Emergency Runbook)

🚨 Tình huống 1: Người dùng đã chuyển khoản ngân hàng nhưng chưa nhận được Credits

  1. Truy cập PayOS Dashboard → Mục Giao dịch → Tìm mã đơn hoặc mã chuyển khoản của khách.
  2. Kiểm tra trạng thái Webhook. Nếu báo thất bại (do timeout mạng), nhấn nút "Gửi lại Webhook" (Resend Webhook).
  3. Hệ thống Ventus Tarot có cơ chế Webhook Idempotent tự động cộng bù Credits an toàn mà không bao giờ bị cộng trùng lặp.

🚨 Tình huống 2: AI đột ngột báo lỗi hoặc hết hạn mức (API Quota Exceeded)

  1. Tạo ngay 1 API Key mới tại Google AI Studio (hoặc đổi sang AI_PROVIDER=openai / anthropic dự phòng).
  2. Vào Vercel → Settings → Environment Variables → Cập nhật giá trị key mới.
  3. Vào tab Deployments → Chọn bản build mới nhất → Nhấn Redeploy. Hệ thống phục hồi trong 30 giây.

🚨 Tình huống 3: Website bị tấn công spam / DDoS

  1. Bật tính năng Attack Challenge Mode (Under Attack) trên Vercel Security hoặc Cloudflare (nếu trỏ DNS qua Cloudflare).
  2. Kiểm tra bảng rate_limits trên Supabase để xác định IP bất thường và thêm vào danh sách chặn.
